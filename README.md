# Computing Through Time

**Computing Through Time** was created to be a web-based interactive experience that demonstrates how humans have developed different ways of representing, storing, and processing information throughout history.

This project explores the progression from early manual counting methods to modern digital concepts, showing how mathematical ideas and computational systems have evolved over time. Through interactive exhibits, users can explore historical number systems including:

- Tally marks - one of humanity's earliest methods of recording quantities
- Abacus - a mechanical counting device used across many cultures for arithmetic calculations
- Roman numerals - a symbolic number system developed by ancient Rome
- Binary numbers - the foundation of modern digital computing

The goal of the project is to connect mathematical concepts with the development of computing technologies and provide an engaging way to understand their historical significance.

# Features

### Interactive Timeline

Explore important milestones in the development of numerical systems and computing history.

Each timeline entry provides:
- Historical context
- Dates and key events
- Explanations of how each development contributed to computing

### Interactive Exhibits

<ins>Abacus Demonstration</ins>: A digital recreation of an abacus that allows users to interact with beads and explore positional values.

<ins>Tally Mark Demonstration</ins>: Shows how simple marks were used as an early method of recording quantities and counting.

<ins>Roman Numeral Converter</ins>: Converts between modern numbers and Roman numeral representations, demonstrating symbolic number systems.

<ins>Binary Converter</ins>: Demonstrates how numbers are represented using the binary system used by modern computers.
